# Xinyu Zhang — Academic Research Website (V7)

## Local preview
Unzip and open `index.html` in a browser. This package contains one homepage, a publications page, a current research page, and four selected design/research project pages. Images are stored in `assets/`.

## Updating your live website
If the site is published using GitHub Pages, edit or upload files in the same GitHub repository and commit them to the publishing branch. The site will rebuild at the same public address.

- Homepage: `index.html`
- Publications: `publications/index.html`
- Dissertation: `research/lingering-spaces/index.html`
- Studio: `projects/school-retrofit/index.html`
- Other projects: subfolders inside `projects/`
- Appearance: `style.css`
- Interactions: `app.js`

Replace image files in `assets/` while retaining filenames to update figures without editing image links. For new images, add files to `assets/` and link them from the relevant project page.

The Studio page contains a four-slide horizontally scrollable design-development sequence. Visitors can use the arrow buttons, swipe or scroll, and click any figure to view the full image. Return links take visitors back to the relevant homepage section.

Before publishing, check that project information, photos, and research materials are permitted for public display. Review the homepage and project pages on desktop and mobile.
